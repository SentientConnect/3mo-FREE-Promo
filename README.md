# Sentient Connect™ Landing Page

Premium multi-page Next.js landing site for Sentient Connect™, AURA Genesis™, SentientOS™, Home Services AURA™, Behavioral Health, DISC Profile, Business Consulting, and Mind | Body | Spirit Triangulation™.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- lucide-react icons

## Local Setup

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Pages

- `/` — Sentient Connect™ home page
- `/aura-genesis` — AURA Genesis™
- `/home-services-aura` — Home Services AURA™
- `/behavioral-health` — behavioral health support infrastructure
- `/disc-profile` — DISC-style profile positioning
- `/business-consulting` — business consulting and systems design
- `/sentientos` — SentientOS™ and wearables coming soon
- `/mbs-framework` — Mind | Body | Spirit Triangulation™
- `/login` — placeholder login page
- `/request-access` — placeholder access request page

## Notes

- The login and request-access forms are visual placeholders.
- Replace them with Supabase, GoHighLevel, or another live workflow when ready.
- Behavioral health page includes a clear non-clinical disclaimer.
